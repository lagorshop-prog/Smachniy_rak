ПУБЛІКАЦІЯ САЙТУ «СМАЧНИЙ РАК» НА CLOUDFLARE PAGES

1. Вміст папки site розмістіть у GitHub-репозиторії та підключіть репозиторій у Cloudflare Pages.
   Важливо: functions/api/order.js має бути саме за шляхом functions/api/order.js у корені проєкту.
2. Build command для звичайного статичного сайту залиште порожньою, Build output directory вкажіть "." (корінь репозиторію з index.html).
3. У Cloudflare Pages → Settings → Variables and Secrets додайте для Production:
   TELEGRAM_BOT_TOKEN — токен від @BotFather (зберегти як Secret)
   TELEGRAM_CHAT_ID — ID приватного чату або групи для заявок.
4. Щоб дізнатись chat_id, відкрийте бота, натисніть Start і надішліть йому повідомлення. Потім отримайте chat_id через Telegram Bot API, використовуючи токен лише приватно. Не публікуйте URL із токеном і не надсилайте токен нікому. Якщо бот не отримує повідомлення, спершу напишіть йому вручну.
5. Зробіть новий deploy після додавання секретів.
6. Перевірте форму на опублікованому сайті. Під час тесту має надійти Telegram-повідомлення. Локальний VS Code Live Server сам по собі не запускає Cloudflare Pages Functions, тому /api/order локально там не запрацює.
7. Для власного домену відкрийте Pages → Custom domains і виконайте DNS-інструкції Cloudflare.

ЗАУВАЖЕННЯ:
- Ніколи не вставляйте TELEGRAM_BOT_TOKEN у HTML або script.js.
- Якщо токен випадково опублікували — перевипустіть його через BotFather.
- Перед відкриттям сайту для всіх варто додати захист від спаму (наприклад, Cloudflare Turnstile) і перевірити форму на production.
- Це базова інтеграція без бази даних: заявки передаються у Telegram, але не зберігаються в адмін-панелі.
