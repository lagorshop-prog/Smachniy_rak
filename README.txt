Raky — сайт продажу австралійських раків

СТОРІНКИ:
- index.html — живі австралійські раки
- malok.html — мальок
- matocne.html — маточне поголів'я

ЦІНИ:
- мальок 1–3 см — 10 грн/шт.
- мальок 3–5 см — 25 грн/шт.
- мальок 5+ см — 50 грн/шт.
- самець — 500 грн/шт.
- самка — 600 грн/шт.

ЗОБРАЖЕННЯ:
У assets/ лежать порожні PNG-файли. Просто замініть їх своїми фотографіями з такими самими назвами.

ЗВОРОТНИЙ ЗВ'ЯЗОК:
Справа екрана є невелика вкладка. Після натискання відкривається форма та номер +380 98 935 05 00.

СОЦМЕРЕЖІ:

КОМЕНТАРІ:
HTML, CSS і JavaScript доповнені пояснювальними коментарями по основних блоках.
